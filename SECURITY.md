# Security policy

## Supported version

Security fixes are applied to the current `main` branch. This hackathon project does not maintain older release branches.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available, or contact the repository owner privately through the profile linked from the repository.

Include the affected route or component, reproduction steps, expected and observed behavior, and the practical impact. Do not include patient data, credentials, access tokens, or other secrets in a report.

Protocol Mirror currently uses fictional demonstration data and public source APIs. It is a research-transparency prototype, not a clinical system and not approved for protected health information.
